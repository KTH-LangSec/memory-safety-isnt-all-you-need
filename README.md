# Memory Safety Isn’t All You Need: Code Reuse Attacks in Memory Safe Languages

This repository contains the code artifacts for the paper on code reuse attacks
in memory safe languages by the title above. In particular, you can find

- [`interpreter`]: The interpreter for the simple imperative language used in
  the model of code reuse attacks presented in Section 5 of the paper.
- [`listings`]: Runnable versions of Listing 1-11.
- [`case-study`]: Runnable versions of the examples given in the Go case study
  (Secion 2.4 of the paper)
